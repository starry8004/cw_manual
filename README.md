# 🚀 쿠팡 윙 상품등록 도우미 (Coupang Wing Helper)

**Alt+알파벳 단축키로 CSV 데이터를 쿠팡 윙에 빠르게 등록하는 크롬 확장앱**

## ✨ 주요 기능

- ⚡ **빠른 입력**: 수동 대비 3~5배 빠른 상품 등록 속도
- 🎯 **직관적 단축키**: Alt+B(Brand), Alt+P(Price) 등 외우기 쉬운 단축키
- 👁️ **안전한 반자동 방식**: 육안 검증으로 오류 방지 및 자동화 탐지 회피
- 🖼️ **이미지 관리**: 체계적인 이미지 폴더 구조 및 자동 인식
- 📊 **추적 가능**: 내부관리번호 체계로 원본 데이터 추적

## 📋 요구사항

- **브라우저**: Chrome 86+ 이상 (File System Access API 지원 필요)
- **운영체제**: Windows, macOS, Linux
- **파일 형식**: CSV (UTF-8 인코딩)

## 🔧 설치 방법

### 1. PapaParse 라이브러리 설치

CSV 파싱을 위해 PapaParse 라이브러리가 필요합니다.

**방법 A: 직접 다운로드 (추천)**
```bash
# lib/ 폴더로 이동
cd lib/

# 브라우저에서 다음 URL 방문
# https://unpkg.com/papaparse@5.4.1/papaparse.min.js
# 페이지 내용 전체를 복사하여 lib/papaparse.min.js 파일로 저장
```

**방법 B: CDN 사용**
`popup/index.html` 파일에서 다음 줄을 수정:
```html
<!-- 현재 -->
<script src="../lib/papaparse.min.js"></script>

<!-- CDN 사용 -->
<script src="https://unpkg.com/papaparse@5.4.1/papaparse.min.js"></script>
```

자세한 내용은 [`lib/README.md`](lib/README.md) 참조

### 2. 아이콘 이미지 생성

크롬 확장앱에 필요한 아이콘 이미지를 생성해야 합니다.

`icons/icon.svg` 파일을 PNG로 변환:
- `icon16.png` (16x16)
- `icon48.png` (48x48)
- `icon128.png` (128x128)

**온라인 도구 사용 (추천)**:
- https://svgtopng.com/
- https://convertio.co/kr/svg-png/

자세한 내용은 [`icons/README.md`](icons/README.md) 참조

### 3. 크롬 확장앱 로드

1. Chrome 브라우저 열기
2. 주소창에 `chrome://extensions/` 입력
3. 우측 상단 **개발자 모드** 활성화
4. **압축해제된 확장 프로그램을 로드합니다** 클릭
5. 이 프로젝트 폴더 선택
6. 확장앱 아이콘이 툴바에 표시됨

## 🎮 사용 방법

### 1️⃣ 초기 설정

1. **확장앱 아이콘 클릭** → 새 창 열림
2. **CSV 파일 선택**
   - 올리브영 등에서 수집한 상품 CSV 파일
   - 필수 컬럼: 브랜드, 상품명, 판매가
3. **이미지 폴더 선택**
   - 상품 이미지가 저장된 폴더 (예: `images/`)
4. **내부관리번호 설정**
   - 브랜드코드: `CP` (Coupang)
   - 수집일자: `1104` (11월 4일)
   - 시작 연번: `001`
   - 생성 예시: `CP1104_001`
5. **변환 시작** 클릭

### 2️⃣ 상품 등록

1. **쿠팡 윙 페이지** 열기
2. **도우미 창**에서 상품 정보 확인
3. **단축키로 데이터 복사**
   - 쿠팡 입력 필드 클릭
   - `Alt+B` (브랜드 복사)
   - `Ctrl+V` (붙여넣기)
   - 다음 필드로 이동
   - 반복...
4. **이미지 등록**
   - `Alt+M`: 대표 이미지 경로 복사
   - `Alt+A`: 추가 이미지 경로 복사
   - 쿠팡 윙에서 붙여넣기
5. **완료 처리**
   - `Alt+N`: 완료 처리 후 다음 상품

## 📁 CSV 파일 형식

### 입력 (원본)
```csv
내부관리번호,브랜드,상품명,할인전금액,판매가,배송비,카테고리,옵션정보,전성분,용량,상품URL
A000000215502,브링그린,브링그린 알로에 97%,6800,6400,2500,선케어 > 태닝/애프터선,...
```

### 출력 (변환 후)
```csv
신규내부관리번호,브랜드,상품명,할인전금액,판매가,배송비,카테고리,옵션정보,전성분,용량,상품URL,상태,올리브영상품번호
CP1104_001,브링그린,브링그린 알로에 97%,6800,6400,2500,선케어 > 태닝/애프터선,...,대기,A000000215502
```

### 필수 컬럼
- `브랜드`: 상품 브랜드명
- `상품명`: 상품 제목
- `판매가`: 판매 가격 (숫자)

### 선택 컬럼
- `할인전금액`, `배송비`, `카테고리`, `옵션정보`, `전성분`, `용량`, `상품URL`


### 변환 후 (내부관리번호)
```
images/
├── CP1104_001/
│   ├── 001.jpg  (대표)
│   ├── 002.jpg  (추가)
│   └── 003.jpg  (추가)
└── CP1104_002/
    └── 001.jpg
```

**이미지 파일 규칙**:
- 001.jpg: 대표 이미지 (썸네일)
- 002~009.jpg: 추가 이미지 (최대 9개)
- 지원 형식: .jpg, .jpeg, .png, .webp

## 💡 사용 팁

### 1. 단축키 학습
- **1단계 (첫 사용, 5분)**: 필수 5개만 외우기 (B, T, P, C, O)
- **2단계 (10회 사용 후)**: 이미지 단축키 추가 (M, A)
- **3단계 (100회 사용 후)**: 완전 자동화, 손이 자동으로 움직임

### 2. 작업 효율화
- 쿠팡 윙 페이지와 도우미 창을 듀얼 모니터에 나란히 배치
- Tab 키로 쿠팡 윙 입력 필드 간 빠르게 이동
- 복사/붙여넣기 전에 육안으로 한 번 더 확인

### 3. 이미지 관리
- 이미지 폴더명을 내부관리번호와 일치시키기
- 대표 이미지는 반드시 001.jpg로 시작
- 권장 해상도: 800x800 이상
- 권장 파일 크기: 5MB 이하

### 4. 데이터 백업
- CSV 변환 전 원본 파일 백업 (자동)
- 중요한 작업 시작 전 수동 백업 권장
- localStorage에 진행 상황 자동 저장

## 🔍 문제 해결

### CSV 파일을 선택할 수 없어요
- Chrome 86+ 이상 버전인지 확인
- File System Access API 지원 브라우저 사용

### 단축키가 작동하지 않아요
1. 크롬 확장앱 페이지(`chrome://extensions/`)에서 확장앱 활성화 확인
2. 단축키 설정: `chrome://extensions/shortcuts`에서 단축키 확인
3. 다른 확장앱과 단축키 충돌 확인

### 이미지 폴더가 인식되지 않아요
1. 폴더명이 내부관리번호와 정확히 일치하는지 확인
   - 예: `CP1104_001` (대소문자 구분)
2. 이미지 파일 형식 확인 (.jpg, .png, .webp)
3. 파일명이 001.jpg, 002.jpg 형식인지 확인

### CSV가 저장되지 않아요
1. File System Access API 권한 허용 확인
2. 파일이 다른 프로그램(Excel 등)에서 열려있지 않은지 확인
3. 자동 저장 설정 확인 (설정 > 자동 저장)

### 상품 개수가 너무 많아 느려요
- 현재 버전은 최대 100개 정도 권장
- 대량 등록 시 여러 CSV 파일로 분할 권장
